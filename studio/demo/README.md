# Blender demo görüntüleri

Bu üç görüntü aynı Blender sahnesinden farklı açılarda alınmıştır.
Dosyaları sahnedeki üç **Load Image From Path** bloğuna şu sırayla ver:

| Giriş | Dosya |
|---|---|
| Kamera 1 | [view_0.png](view_0.png) |
| Kamera 2 | [view_2.png](view_2.png) |
| Kamera 3 | [view_4.png](view_4.png) |

Studio'da senaryoyu aç, ilgili **String Input** bloğundan dosyayı seç
veya deponun bulunduğu bilgisayardaki tam yolunu gir. Üç girişin sırası
**Çok Kameralı 3D** bloğunda değişmesin. Örnek için **Kart boyu (mm)** 100
ve **Kargo modu** açık olmalı. Gerçek kamera kurulumunda bu dosya
girişlerini kamera bloklarıyla değiştir.
